## 📌 Featured Work

| Project | What it is |
| :--- | :--- |
| **[malaria-llm-cdss](https://github.com/jemiridaniel/malaria-llm-cdss)** | Hybrid rule-based + LLM clinical decision support for malaria diagnosis. Lifted accuracy from a **30.62% baseline to 87.22%** across 1,682 cases while keeping 100% critical-case detection. Runs fully offline via Ollama. *Manuscript in journal submission.* |
| **[covid-llm-cdss](https://github.com/jemiridaniel/covid-llm-cdss)** | 5-class COVID-19 severity assessment ensembling a 500K-patient comorbidity model with a lab-based model — **86.0% accuracy, Cohen's Kappa 0.798**, validated with McNemar and bootstrap CI. |
| **[iba-triage](https://github.com/jemiridaniel/iba-triage)** | Iba — a fever-triage copilot built for the Nebius × NVIDIA Global AI Hackathon. |
| **Pulse** *(private)* | AI-native social platform for Nigerian communities. FastAPI · PostgreSQL · React Native. |
